# 用户日记系统 — ES 学习项目需求文档

> 定位：一个用于学习 Elasticsearch 的练手项目。用户每天把"所见所闻"写成日记存入 ES，支持标签分类、检索、按日期浏览。
> 目标 ES 服务：`http://127.0.0.1:9200/`

---

## 一、背景与目标

通过实现一个"用户日记"应用的数据写入与检索能力，覆盖 ES 的核心数据类型（`text`/`keyword`/`date`/`integer`/`geo_point`/`boolean`）与核心能力（全文检索、精确过滤、排序、分页、聚合统计），作为 ES 入门的实战练习。

---

## 二、数据模型（索引设计）

索引名：`diary`

| 字段名 | 类型 | 说明 |
|---|---|---|
| `summary` | `text`（含 `.keyword` 子字段） | 日记概要，全文检索 + 可精确匹配/排序 |
| `content` | `text`（`ik_max_word` 分词） | 日记详情，核心全文检索字段 |
| `tags` | `keyword` 数组 | 分类标签，**一篇日记可打多个标签**，如 `["经济", "日记"]`；不分词，用于精确过滤与聚合统计 |
| `date` | `date` | 日记所记录的日期（用户所见所闻发生的日期） |
| `mood` | `keyword` | 心情（枚举：开心/平静/难过/焦虑...），精确匹配 + 聚合 |
| `mood_score` | `integer`（1-10） | 心情量化分值，用于趋势统计（如按月均值） |
| `location_name` | `keyword` | 地点名称，精确匹配/聚合"去过哪些地方" |
| `location` | `geo_point` | 地理坐标，用于地理位置检索练习 |
| `weather` | `keyword` | 天气（可选字段） |
| `word_count` | `integer` | 日记字数，自动统计，数值聚合练习 |
| `is_private` | `boolean` | 是否私密，布尔过滤练习 |
| `created_at` | `date` | 系统写入时间（区别于 `date`，体现自动时间戳做法） |

> 建索引命令（`PUT /diary`）将在下一步给出，当前先确认字段设计。

## 三、页面与功能清单

### 1. 标签列表页
- **功能**：展示系统中出现过的所有标签，及每个标签下的日记篇数
- **交互**：点击某个标签 → 跳转到"日记列表页"，并带上该标签作为筛选条件
- **依赖能力**：ES `terms` 聚合（按 `tags` 字段分组计数）

### 2. 日记列表页
- **入口**：① 首页"全部日记"入口；② 标签列表页点击某标签进入
- **排序**：默认按 `date` **倒序**（最新的排最前）
- **分页**：常规分页（第 1/2/3 页），对应 ES 的 `from + size`
- **每条展示字段**：`summary`、`date`、`tags`、`mood`（不返回 `content` 全文，减少列表接口数据量）
- **交互**：点击某一条 → 进入"日记详情页"

### 3. 日记详情页
- **功能**：展示一篇日记的完整信息
- **展示字段**：全部字段，含完整 `content`

### 4. 搜索
- **交互入口**：顶部搜索框，输入关键字
- **检索范围**：对 `summary` + `content` 做全文模糊匹配
- **排序**：按相关性得分 `_score` 倒序（搜索场景下"越匹配"优先于"越新"）
- **结果展示**：复用"日记列表页"的卡片样式与分页逻辑
- **标签叠加筛选（本版本默认包含）**：搜索时可选叠加 `tag` 参数，在全文匹配基础上再按标签精确过滤。该筛选条件可选，不传则为全库搜索。

## 四、接口清单

### 1. 获取全部标签
```
GET /tags

Response:
{
  "tags": [
    { "name": "经济", "count": 12 },
    { "name": "日记", "count": 34 },
    { "name": "时政", "count": 5 }
  ]
}
```
ES 实现：对 `tags` 字段做 `terms` Bucket 聚合。

---

### 2. 获取日记列表（全部 / 按标签筛选）
```
GET /diaries?tag={可选}&page=1&size=10

Response:
{
  "total": 56,
  "page": 1,
  "size": 10,
  "items": [
    {
      "id": "xxx",
      "summary": "今天去公园散步，天气很好",
      "date": "2026-10-12",
      "tags": ["日记"],
      "mood": "平静"
    }
  ]
}
```
ES 实现：
- 不传 `tag`：`match_all` + `sort: [{date: desc}]` + `from/size`
- 传 `tag`：`bool.filter` 中加一条 `term` 精确匹配该标签

---

### 3. 获取日记详情
```
GET /diaries/{id}

Response:
{
  "id": "xxx",
  "summary": "...",
  "content": "完整日记正文...",
  "tags": ["日记", "经济"],
  "date": "2026-10-12",
  "mood": "平静",
  "mood_score": 7,
  "location_name": "人民公园",
  "location": { "lat": 31.23, "lon": 121.47 },
  "weather": "晴",
  "word_count": 320,
  "is_private": false,
  "created_at": "2026-10-12T20:15:00"
}
```
ES 实现：`GET /diary/_doc/{id}`，按文档 ID 直接取完整文档。

---

### 4. 搜索日记
```
GET /diaries/search?keyword={关键字}&tag={可选}&page=1&size=10

Response:（结构同"日记列表"接口）
```
ES 实现：
- 核心查询：`multi_match`，同时匹配 `summary` 和 `content` 两个字段
- 可选叠加：若传 `tag`，在 `multi_match` 外再套一层 `bool.filter` 做标签精确过滤（与接口2的标签过滤逻辑复用）
- 排序：按 `_score` 倒序（不显式指定 `sort` 即为 ES 默认行为）

## 六、执行顺序建议

1. 按本文档「数据模型」建索引（`PUT /diary`，含 mapping）
2. 写入若干条测试日记数据（覆盖多标签、多心情、含/不含地理位置等场景）
3. 依次验证：标签聚合 → 列表分页排序 → 详情取值 → 全文搜索 → 标签叠加搜索
4. 把每一步命令与返回结果贴给我，整理成验收文档
